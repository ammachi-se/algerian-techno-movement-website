# Algerian Techno Movement

Site vitrine artistique pour un collectif de musique électronique algérien.

## Stack
- React + Vite
- React Router
- GSAP (animations)
- Font Awesome (icônes via CDN)

## Démarrage (client)
```powershell
cd "client"
npm install
npm run dev
```

## Structure
- `client/src/components/Layout.jsx` : navbar, preloader, cursor custom, reveals
- `client/src/pages/*` : pages principales
- `client/src/styles.css` : styles globaux

## Notes
Le backend `server/` existe mais n’est pas utilisé pour le moment.
